# TypingMind Extensions

このリポジトリは、TypingMind向けの拡張機能を複数提供するためのものです。拡張機能の一例としてUI Balancerが含まれており、TypingMindのユーザーインターフェースを動的に調整することで、より快適な操作性を実現しています。

## インストール方法

### TypingMind拡張機能画面からのインストール

1. TypingMindの拡張機能画面を開いてください。
2. 拡張機能のJSファイルパス入力欄に、以下のURLを入力してください。

   ```plaintext
   https://amizok.github.io/typingmind-extensions/extensions/ui-balancer-ja.js
   ```

3. インストールを確定すると、TypingMind環境内で拡張機能が自動的に読み込まれます。

## 使用方法

TypingMindが正しく動作している環境では、拡張機能が自動的に適用され、UIの動的な調整などが行われます。
